# Проблематика

## JS - ~~НЕТИПИЗИРОВАН~~ -- частая ошибка новичков

## JS - это язык со **слабой и динамической типизацией**

| Слабая                                                                                                         | Динамическая                                                |
| -------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| **JS** имеет свойство работать с разными типами данных с помощью **неявного приведения типов** (type coercion) | Типы определяются в рантайме, а не на этапе компиляции кода |

## Какие проблемы из-за этого?

- Сложность в поддержке больших проектов
  - Данных много и нет четкого описания
- На этапе написания кода работу с типами приходится проводить в ручную
- Дебаг и тестирование кода усложняются в разы
  - Отсюда усложняется анализ кода
- Отсутствие нормального автокомплита в IDE

# TypeScript

**TypeScript** - все, что есть в JS и расширяет его
**TypeScript** - ЯП со статической типизацией (явной или выводимой + структурной)

## Что такое _статическая типизация_

**Статическая типизация** - типы проверяются на этапе _компиляции_, а не _выполнения_. **TypeScript** определяет типы с помощью **явной** (когда мы сами указываем типы) или **выводимой** (мы присвоили переменной число, а ts это распознал и установил тип number) типизации

## Что такое _структурная типизация?_

Типы в TS **взаимозаменяемые**, если они одинаковы

```typescript
type User = {
	firstName: string;
	lastName: string;
};

type Person = {
	firstName: string;
	lastName: string;
};

const Vasya: User = {
	firstName: 'Vasya',
	lastName: 'Pupkin',
};

function sayHello(person: Person): string {
	return `Hello! My names ${person.firstName} ${person.lastName}`;
}

// User и Person взаимозаменяемые
console.log(sayHello(Vasya));
```

## Надтипы и подтипы

**Надтип** - тип с полями
**Подтипы** - тот тип, у которого есть поля родителя и свои собственные

**Подтип** может присваиваться **надтипу** (при присваивании поля, которых нету в надтипе, будут игнорироваться TS и их нельзя будет использовать).
**Надтип** НЕ может присваиваться **подтипу** (у надтипа не хватает нужные полей)
